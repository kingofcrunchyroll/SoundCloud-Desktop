# SoundCloud Desktop <img src="https://cdn.worldvectorlogo.com/logos/soundcloud-icon-1.svg" alt="logo" width="48" align="absmiddle">
An unofficial Desktop App for SoundCloud powered by WebView2
> [!IMPORTANT]
> This is an independent project and is not affiliated with, endorsed by, or sponsored by SoundCloud.

# Features

## Discord Rich Presence

[insert image here]

###### Lets your friends see what song you're currently listening to! Similar to what Spotify does.

## System Tray Support

Instead of stopping your music when you close the app, it will go into the System Tray, keeping your music playing in the background!

## Mini Player

[insert image here]

###### Lets you see what you're currently listening to no matter where you are, with media controls to seek between songs or pause!
